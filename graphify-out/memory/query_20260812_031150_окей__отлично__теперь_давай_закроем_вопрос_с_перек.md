# Q: окей, отлично. теперь давай закроем вопрос с перекодированием видео из .ts в mp4. какие у нас варианты?

## Answer

Expanded query tokens: video, download, media, segment, archive, file, url, fetch, index, quality, wildberries, save. Current flow fetches an HLS playlist and all .ts segments in downloadMedia(), concatenates them into a video/mp2t Blob, and names the media video-1.ts. A sampled WB segment carries H.264/AVC video and AAC audio, so conversion should be a lossless remux/transmux rather than transcoding. Recommended: native FFmpeg streamcopy in a production BFF; if the app stays static, mux.js in the browser. ffmpeg.wasm is a heavier fallback; WebCodecs alone is insufficient.
