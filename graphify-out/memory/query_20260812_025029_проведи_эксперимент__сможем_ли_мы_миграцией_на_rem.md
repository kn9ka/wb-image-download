# Q: проведи эксперимент, сможем ли мы миграцией на remix пофиксить проблему фетча // Mock for https://www.wildberries.ru/__internal/card/cards/v4/detail.

## Answer

Expanded from original query via graph vocab: [wildberries, product, media, fetch, api, card, detail, client, server, query, react, vite]. HomePage calls getProductMedia in the browser. Experiment result: the exact www.wildberries.ru/__internal endpoint returns HTTP 403 even from Node, while card.wb.ru/cards/v4/detail returns HTTP 200 with product id 604174866 and pics 20 but no Access-Control-Allow-Origin. A server-side Remix loader can therefore fix the browser CORS boundary only by fetching the public card.wb.ru endpoint; Remix migration does not make the blocked internal endpoint work and is unnecessary if a smaller BFF/serverless route is available.
